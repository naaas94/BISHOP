## 2. Shared contracts

(Same as T1 packet §2 — binding: Error envelope, `ProcessingState`, H3 explicit `BEGIN`/`COMMIT`/`ROLLBACK`, N3 SUBMITTED→FAILED normalization, retry mapping §6.2 L300–306, provenance assertion helper for content path §5.3 step 6.)

**Decision log path:** `.dev/decision-logs/m1-state-kernel/T2-transition-engine.md`

**H3 pattern (binding):**
```python
await conn.execute("BEGIN")
try:
    # COMPLETE + field writes + next QUEUED
    await conn.commit()
except Exception:
    await conn.rollback()
    raise
```

**Atomic claim mapping (binding):** `DISCOVERED→RELEVANCE_QUEUED`, `RELEVANCE_PASSED→SCRAPE_QUEUED`, `SCRAPED→ENRICHMENT_STAGE1_QUEUED`, `ENRICHMENT_STAGE2_QUEUED→ENRICHMENT_STAGE2_CLAIMED`. `VECTOR_WRITE_QUEUED`: no claim.

**Retry mapping (binding):** `SCRAPE_FAILED→RELEVANCE_PASSED`, `ENRICHMENT_STAGE1_FAILED→SCRAPED`, `ENRICHMENT_STAGE2_FAILED→ENRICHMENT_STAGE2_QUEUED`, `VECTOR_WRITE_FAILED→VECTOR_WRITE_QUEUED`.

**Lock-state sweep resets (binding):** `RELEVANCE_QUEUED→DISCOVERED`, `SCRAPE_QUEUED→RELEVANCE_PASSED`, `ENRICHMENT_STAGE1_QUEUED→SCRAPED`, `ENRICHMENT_STAGE2_CLAIMED→ENRICHMENT_STAGE2_QUEUED`.
