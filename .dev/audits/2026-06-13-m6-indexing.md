### F-004 — M6 integration test sys.modules pollution (major)

**Expected:** Full-suite isolation — state-worker `app.config` reload tests independent of vector-writer.  
**Found:** Running `pytest tests/test_m6_integration.py tests/test_state_worker_config.py::test_config_env_round_trip` fails: `_reload_config()` loads `services/vector-writer/app/config.py` (no `RETRY_MAX_ATTEMPTS=7` from env). Pre-M6 @ `ac991e9`, `test_config_env_round_trip` **passes** in isolation.

**Evidence:** `tests/test_m6_integration.py` permanently inserts `services/state-worker` and repo roots on `sys.path` and imports `app.main` / state-worker `app.*` without restoring `sys.modules` after vector-writer stack loads inside `_load_vector_writer_stack`.

**Action:** Add `app` module teardown fixture to `test_m6_integration.py` (mirror `test_vector_writer_loop.py` pattern) before claiming full-suite green.

### F-008 — G5 live gate not executed (major)

**Expected:** Charter exit gate G5 includes subjective semantic quality on real embeddings; plan binds fixture gate for CI and optional live probe.  
**Found:** `test_g5_quality_gate_live` skipped unless `BISHOP_G5_LIVE=1`; not run at handoff. Fixture gate passes with deterministic orthogonal vectors — does not validate MiniLM semantics on enrichment output.

**Evidence:** Handoff §8.1, §8.4 disposition "treat-as-prediction" for 384-dim real-model assumption.

**Action:** Charter owner runs `BISHOP_G5_LIVE=1 pytest tests/test_g5_quality_gate.py -m heavy` before M7 entry (handoff pre-declared trigger for model upgrade if live fails).
