## 5. Detailed findings (major+)

### F-002 — Plan artifacts not in HEAD

**Expected:** Plan §8.2 artifact chain resolvable via `git show HEAD:<path>` for audit archaeology.  
**Found:** `.dev/plans/m0-workshop/` (plan, context map, five packets) is untracked; `git show HEAD:.dev/plans/m0-workshop/plan.md` fails.  
**Evidence:** `git status` shows `?? .dev/plans/`; plan §8.2 table marks these **No** for HEAD resolution.  
**Action:** Commit `.dev/plans/m0-workshop/` before merge; re-record closure SHA if commit advances tree.

### F-003 — Fresh onboarding breaks host port mapping

**Expected:** Per plan §1 and README quick start, a developer copying `.env.example` to `.env` and running `docker compose up` should reach `query-api` on `localhost:8080` and `ui` on `localhost:8081` (G1 host curls).  
**Found:** With only `.env.example` (no `QUERY_API_HOST_PORT` / `UI_HOST_PORT`), `docker compose --env-file .env.example config` emits port entries with `target: 8000` / `target: 80` but **no `published` host port**. `verify-g1.sh` step 5–6 default to 8080/8081 via shell fallbacks and would fail against an unmapped stack.  
**Evidence:** Adversarial run at audit time (clean shell env, `--env-file .env.example`); T4 decision log defers `.env.example` port entries; README step 1 only copies `.env.example`.  
**Root cause:** Compose interpolation `${QUERY_API_HOST_PORT}` without default + deferred `.env.example` documentation.  
**Action:** Add `QUERY_API_HOST_PORT=8080` and `UI_HOST_PORT=8081` to `.env.example` (or compose `:-` defaults per rejected alternative — prefer `.env.example` for contract clarity).

### F-004 — G1 script not run end-to-end

**Expected:** T5 kill criteria require runtime verification (nine containers, no restarts, volume writability, in-container health).  
**Found:** Plan §8.1 documents pytest 61/61 pass and live Docker spot-checks, but `bash scripts/verify-g1.sh` was **not** executed end-to-end on handoff host (bash unavailable in PowerShell session). Static contract covered by `tests/test_verify_g1.py` (6 cases).  
**Evidence:** Plan §8.1 explicit deferral; auditor re-ran pytest — 61 passed.  
**Action:** Run `bash scripts/verify-g1.sh` on a bash-capable host with Docker before merge sign-off. Downgraded from process-violation because plan explicitly documents manual gate and static falsifiers — but runtime kill criteria remain unverified at handoff.
