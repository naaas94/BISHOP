## 6. Detailed findings

### F-001 — context-map-stale (major)

**Expected:** Context map reflects pre-execution codebase at scout SHA.  
**Found:** Scout @ `e207960` predates all M7 implementation; every `direct` file-map row (query-api/ui stubs, missing CLI, m0 tags) diverged.  
**Evidence:** `git diff e207960..1be89cb --stat`; context-map §File map rows 43–59.  
**Action:** Re-exploration is orchestrator decision; expected for greenfield stub→service graduation. Stale-qualified for scout prediction outcomes.

### F-002 — artifact-not-in-HEAD (major)

**Expected:** Handoff §8 artifact committed at closure SHA per plan §8 and handoff L260.  
**Found:** `.dev/plans/m7-read-path/handoff.md` exists on disk; `git cat-file -e HEAD:.dev/plans/m7-read-path/handoff.md` fails.  
**Evidence:** `git status` shows `?? handoff.md`; handoff self-documents "Lands in follow-up commit after `1be89cb`".  
**Action:** Commit handoff before M8 entry gate; breaks post-merge audit archaeology until committed.

### F-004 — intent-drift (minor)

**Expected:** Plan §0 Flag 2: entry reads use **read-only `aiosqlite`** connection.  
**Found:** `sqlite_reader.py` uses stdlib `sqlite3.connect(uri, uri=True)` with `mode=ro`; no `aiosqlite` import in query-api.  
**Evidence:** `services/query-api/app/sqlite_reader.py:L83-L84`; `test_read_entry_opens_sqlite_read_only` asserts `mode=ro`.  
**Behavioral contract honored:** read-only, no writes, no state transitions. Library choice differs. Absorbed — see divergence log.

### F-005 — coverage-gap (major)

**Expected:** Full regression suite runnable for program hygiene.  
**Found:** At `1be89cb`, monolithic `pytest tests/` → **461 passed, 55 failed, 10 errors, 1 skipped**. Pre-M7 baseline @ `e207960` → **422 passed, 2 failed**. M7 gate slices pass **136/136**.  
**Evidence:** Failures cluster on `ImportError` / wrong `app` module after query-api/ui tests load `services/*/app` into `sys.modules['app']`. `verify-m7.sh` mitigates via isolated subprocesses for models + integration.  
**Action:** Program hygiene follow-up — not M7 exit gate per plan §2 Tests binding (`scripts/verify-m7.sh`). Waived for milestone closure with residual risk.

### F-006 — coverage-gap (major)

**Expected:** Charter M7 exit gate G4 (full e2e ArXiv → INDEXED), entry gates G5 live + G6 sampling.  
**Found:** No automated G4/G5-live/G6 in default `verify-m7.sh`; optional `BISHOP_M7_REQUIRE_GATES=1` runs live G5 heavy test only.  
**Evidence:** Plan §0 Flag 5 resolution; T8 kill criteria; CHANGELOG T8 line; handoff §8.1.
