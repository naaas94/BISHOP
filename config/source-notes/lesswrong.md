# lesswrong

Adapter: `services/scraper/app/adapters/lesswrong.py`  
Shape: **4 — article**. Manifest is **title only** (no abstract). Lowest-evidence text shape.

## Taste

Wanted when the post is practice, systems, eval, or a concrete write-up you would steal from. Alignment-theory / long-horizon philosophy is usually the wrong flavor for this profile even when the title is “about AI.”

No LW stamp set yet. Park more readily than you would a paper: the title cannot carry a core decision.

## Machine today

- Spec backfill window 30 days; live overlay **7 days**.
- 7-day rewind added **~2** rows. Low volume, not a flood.
- Shape law: do not invent an abstract. Ambiguous title → park (or reject if the title itself is clearly excluded).
- Gate 1: same pin.

## Intel

- Thin live sample. Do not tune the shared rubric from two LW titles.

## Do not

- Treat LW like ArXiv (there is no abstract).
- Widen the window to “get more essays” while GitHub’s bar is still wrong.
